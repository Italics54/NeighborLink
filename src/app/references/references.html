Code Stack

This website utilizes Angular, a clean and scalable front-end framework that is TypeScript-based and optimized for performance, maintainability, and structured development powered by Google. All styling is implemented using standard CSS written and maintained by our team without the use of external CSS frameworks, allowing for full control over layout and theming across the site.

Additional Libraries Utilized

Work Log

Attached below is the official work log documenting design and development progress.

Download PDF
  • @angular/core: Core framework for components, directives, and dependency injection
  • @angular/material: Accessible UI components based on Material Design
  • font-awesome: Scalable vector icons and social logos
  • @angular/ssr: Server-Side Rendering for SEO and performance
  • express: Node.js server framework used for SSR handling
  • rxjs: Reactive programming with observables
  • zone.js: Async execution context for Angular change detection
  • typescript: Strongly typed JavaScript for maintainable code
  • prettier: Automated code formatting tool
  • jasmine & karma: Unit testing framework and test runner
  • @angular/router: Navigation, routing, and lazy loading
  • @angular/forms: Template-driven and reactive forms
  • @angular/build: Build system for compilation and optimization
  • Open AI: OpenAI’s GPT-4 API was used to generate responses for the website chatbot. The content and logic were integrated into the NeighborLink.
  • Angular AuthService: Used for handling user login, signup, and session management.
  • Vercel: Hosting and deployment of the Angular application and serverless API functions.
  • Google Drawings: Creating map and map icons for resources
